# AVVD.AI — поточна теза проєкту

## Робоче формулювання

AVVD.AI можна описати як спробу побудувати community-driven AI platform direction на стику трьох площин:

1. **Universal assistant / orchestration shell**
   - routing між моделями;
   - tools / computer use / browser use;
   - agent loops;
   - memory / retrieval;
   - multimodal interaction.

2. **Skills / packaged use cases**
   - окремі skill-модулі;
   - вузькі практичні сценарії;
   - можливість freemium / pro / commercial packaging.

3. **GitHub-first community project**
   - repository / organization / RFC;
   - roadmap і backlog;
   - source-available або open contribution model;
   - community participation в обговоренні та, можливо, розробці.

## Чому це може бути цікаво

AVVD.AI потенційно цікаве не як “ще один чат”, а як спроба створити оболонку або екосистему, яка:
- поєднує кілька класів можливостей;
- дає місце для вузьких skill-based продуктів;
- може бути осмислена й розвинена публічно через GitHub-first процес.

## Чому тут є ризик

Головний ризик у тому, що ці три лінії можуть змішатися в занадто широкий vision blob:
- assistant platform;
- skill marketplace;
- infra/tooling;
- community governance.

У такому разі стає незрозуміло:
- що є ядром;
- що є MVP;
- що є другою фазою;
- за якими критеріями взагалі вимірювати успіх.

## Головне питання

Не “чи прикольна ідея”, а:

**Який найменший реалістичний центр AVVD.AI, який має сенс будувати першим?**
