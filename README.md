# AVVD.AI — Community Deliberation Repo

Цей репозиторій створений як публічний майданчик для обговорення ідеї AVVD.AI.

## Що таке AVVD.AI

AVVD.AI зараз розглядається як напрям на перетині трьох ліній:
- універсальний AI-помічник / orchestration shell;
- екосистема skills / packaged use cases;
- community-driven GitHub-first проєкт із RFC, roadmap і відкритим обговоренням.

У матеріалах, що стали основою для цього репозиторію, згадуються такі вузли:
- browser / computer use;
- voice / realtime interaction;
- memory / retrieval / vector storage;
- supervisor + specialist agents;
- n8n / automation / integrations;
- skills marketplace або skill packs;
- source-available / GitHub Organization / community contribution.

## Мета цього репозиторію

Не “продати” ідею, а чесно розібрати:
- чи є тут справді сильне ядро;
- який найменший реалістичний MVP;
- що є надбудовою, а що ядром;
- які технічні, ринкові та організаційні ризики критичні;
- чи є достатній інтерес і ресурс у спільноти.

## Як брати участь

1. Прочитай [docs/project-thesis.md](docs/project-thesis.md).
2. Подивись [docs/open-questions.md](docs/open-questions.md).
3. Напиши свою позицію в GitHub Discussions.
4. Якщо вважаєш ідею сильною — поясни, де саме її ядро.
5. Якщо вважаєш її слабкою — поясни, що саме не сходиться і що могло б змінити твою думку.

## Принцип обговорення

Це не батл за лайки і не пітч-пост.

Нас цікавить:
- найсильніший аргумент **за**;
- найсильніший аргумент **проти**;
- які припущення вже мають підстави;
- які припущення ще порожні;
- що треба довести до рішення про MVP.

## Структура репозиторію

- `docs/project-thesis.md` — коротке пояснення, що таке AVVD.AI у поточному формулюванні.
- `docs/open-questions.md` — відкриті питання до спільноти.
- `docs/summary.md` — нейтральний summary, який оновлюється після обговорень.
- `DISCUSSION-POST.md` — текст для pinned discussion.
- `MEETING-RUNBOOK.md` — сценарій для мітапу.
- `CONTRIBUTING.md` — правила участі.

## Важливий дисклеймер

Якщо в репозиторії є HTML board або інші локальні інструменти, їх слід розглядати як **рамку для дискусії**, а не як автоматичний суддя або об'єктивний вимірювач істини.
